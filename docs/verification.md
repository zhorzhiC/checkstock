# Проверки сдачи

Дата: 12 ноября 2026 года.

## Выполнено

- Python 3.12.10, PostgreSQL 18.6, Linux-контейнеры Docker Desktop.
- 32 интеграционных теста на настоящей PostgreSQL 18: все пройдены, предупреждений нет. Использован финальный зафиксированный набор зависимостей.
- Повторный аудит `pip-audit -r requirements.lock`: проверено 29 пакетов, известных уязвимостей не найдено. Снимок результата — `dependency-audit.json`. Это результат на дату проверки, а не гарантия отсутствия будущих уязвимостей.
- Проверен синтаксис JavaScript через `node --check app/static/app.js`.
- Проверен перезапуск финального контейнера: состояние API до и после полностью совпадает, сохранены четыре документа и четыре события; `/health` возвращает `ok`.
- В отдельной браузерной копии выполнены нехватка 12 при 10 на Севере, предложенное перемещение 2 с Юга, приёмка и её повтор, резерв/отмена FBS, новый резерв и отправка, отправка/приёмка FBO, архивирование Севера с остатком.
- Через HTTP подтверждён итог этой копии: на ФФ 18, к клиенту 3, на маркетплейсе 4; учтены все 25 единиц. Для SKU-101: 9 + 3 + 4 = 16. Архивный Север содержит 14 единиц двух SKU; к отправке на действующих ФФ доступны 4.
- Основная демонстрация на `localhost:8000` сохраняет начальные 25 единиц и четыре приходных документа. Браузерный сценарий выполнялся в отдельной базе на порту 8001.
- Проверены пустой поиск, восстановление строк после очистки запроса, Escape и нахождение клавиатурного фокуса внутри диалога.
- При ширине 1280 и 1440 px проверена геометрия DOM: горизонтального выхода всей страницы за viewport нет. Таблица на узком экране прокручивается внутри своего контейнера.

## Ограничение визуальной проверки

Интерфейс просмотрен во встроенном браузере. Его захват при заданном широком viewport показывал только часть видимой панели; полный скриншот получить не удалось. При попытке открыть полноразмерный просмотр через Chrome компьютерная автоматизация остановилась, поскольку не смогла надёжно определить текущий URL. После этого дальнейшее управление браузером не выполнялось.

Поэтому полный визуальный просмотр каждого экрана при 1280/1440 px не заявляется. Проверка этих размеров подтверждена геометрией DOM, сквозные действия — состоянием интерфейса и независимыми числами API. Финальное обновление серверных зависимостей дополнительно проверено HTTP-тестами; функциональная логика JavaScript не менялась, добавлена доступная подпись ссылки навигации.
